# Security policy

This portfolio project has not received an independent security audit. It depends on a security-maintained Qt WebEngine runtime. Only the latest project revision is maintained; no security response SLA is promised.

For sensitive reports, use the repository's GitHub private vulnerability reporting feature if its owner has enabled it. If unavailable, open an issue requesting a private contact without including exploit details, personal data, credentials or browsing logs. Do not assume an unconfigured mailbox exists.

Include the project revision, OS, exact Qt/Chromium version, minimal reproduction and expected security boundary. Upstream Qt/Chromium vulnerabilities should also be reported through their official security channels.
